## 3. Теоретическая часть

### 3.1 Архитектура голосового ассистента

Система работает в три последовательных этапа:

```
Микрофон → [Звук] → Vosk → [Текст] → ML-классификатор → [Намерение] → Действие
```

1. **Захват звука** — `sounddevice` непрерывно читает поток с микрофона и складывает блоки байт в очередь (`queue.Queue`)
2. **Распознавание речи** — `vosk.KaldiRecognizer` конвертирует байты аудио в русский текст
3. **Классификация команды** — логистическая регрессия на основе обучающего набора (`words.py`) определяет, какое действие нужно выполнить
4. **Исполнение** — вызывается соответствующая функция из `skills.py`, результат озвучивается через `voice.py`

### 3.2 Как работает классификатор команд

Используется подход **«мешок слов» (Bag of Words)**:

1. **CountVectorizer** преобразует строку-команду в числовой вектор: каждая уникальная лексема во всём обучающем наборе получает свой индекс, значение в векторе — количество вхождений в строке.
2. **LogisticRegression** обучается сопоставлять такой вектор с меткой-классом (строкой с именем функции и ответом).
3. При распознавании новой фразы она точно так же векторизуется, и классификатор выдаёт наиболее похожий класс из обученного набора.

Пример из `words.py`:
```python
data_set = {
    'какая погода':        'weather сейчас скажу',
    'запусти браузер':     'browser запускаю браузер',
    'выключи компьютер':   'offpc отключаю компьютер',
    ...
}
```
Ключ — образцы фраз пользователя, значение — `<имя_функции> <ответ ассистента>`.

### 3.3 Триггерное слово

Ассистент реагирует только на команды, в которых присутствует триггерное слово (`крендель` / `кренделек`). Это экономит вычислительные ресурсы и исключает случайные срабатывания.

```python
TRIGGERS = {'крендель', 'кренделек'}
```

```python
import pyttsx3

engine = pyttsx3.init()

def speaker(text):
    engine.say(text)
    engine.runAndWait()
```

### Шаг 2. Навыки ассистента (`skills.py`)

Каждый «навык» — отдельная функция без аргументов.

```python
import webbrowser
import sys
import subprocess
import requests
import voice

def browser():
    webbrowser.open('https://www.youtube.com', new=2)

def weather():
    try:
        params = {
            'q': 'Vladivostok',
            'units': 'metric',
            'lang': 'ru',
            'appid': 'ВАШ_API_КЛЮЧ'   # Получить на openweathermap.org (бесплатно)
        }
        r = requests.get('https://api.openweathermap.org/data/2.5/weather', params=params)
        w = r.json()
        voice.speaker(f"На улице {w['weather'][0]['description']} {round(w['main']['temp'])} градусов")
    except Exception:
        voice.speaker('Не удалось получить данные о погоде')

    sys.exit()

    pass  # Ответ уже произнесён в recognize()
```

### Шаг 3. Обучающий набор и триггеры (`words.py`)

```python
TRIGGERS = {'крендель', 'кренделек'}

data_set = {
    'какая погода':           'weather сейчас скажу',
    'какая погода на улице':  'weather боишься замерзнуть?',
    'сколько градусов':       'weather можешь выглянуть в окно, но сейчас проверю',
    'запусти браузер':        'browser запускаю браузер',
    'открой браузер':         'browser интернет активирован',
    'отключись':              'offBot отключаюсь',
    'привет':                 'passive и тебе привет',
    'как дела':               'passive работаю в фоне, не переживай',
    'что ты умеешь':          'passive умею узнавать погоду и открывать браузер',
}
```

**Чем больше вариантов фраз** для одной команды — тем лучше классификатор справляется с разнообразными формулировками.

### Шаг 4. Главный модуль (`app.py`)

```python
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.linear_model import LogisticRegression
import sounddevice as sd
import vosk
import json
import queue

import words
from skills import *
import voice

q = queue.Queue()
model = vosk.Model('vosk-model')
device = sd.default.device
samplerate = int(sd.query_devices(device[0], 'input')['default_samplerate'])


def callback(indata, frames, time, status):
    """Помещает блок аудио в очередь."""
    q.put(bytes(indata))


def recognize(data, vectorizer, clf):
    """Проверяет триггер, классифицирует команду и выполняет действие."""
    trg = words.TRIGGERS.intersection(data.split())
    if not trg:
        return

    text_vector = vectorizer.transform([data]).toarray()[0]
    answer = clf.predict([text_vector])[0]

    func_name = answer.split()[0]             # первое слово — имя функции
    response_text = answer.replace(func_name, '', 1).strip()

    voice.speaker(response_text)
    exec(func_name + '()')                    # вызов функции-навыка


def main():
    # Обучение классификатора при запуске
    vectorizer = CountVectorizer()
    vectors = vectorizer.fit_transform(list(words.data_set.keys()))

    clf = LogisticRegression()
    clf.fit(vectors, list(words.data_set.values()))

    del words.data_set  # Освобождаем память

    # Запуск потока прослушивания
    with sd.RawInputStream(samplerate=samplerate, blocksize=16000,
                           device=device[0], dtype='int16',
                           channels=1, callback=callback):
        rec = vosk.KaldiRecognizer(model, samplerate)
        print('Ассистент готов. Скажите триггерное слово...')
        while True:
            data = q.get()
            if rec.AcceptWaveform(data):
                text = json.loads(rec.Result())['text']
                recognize(text, vectorizer, clf)


if __name__ == '__main__':
    main()
```

## 8. Разбор типичных ошибок

| Симптом | Вероятная причина | Решение |
|---------|-------------------|---------|
| `No module named 'vosk'` | Библиотека не установлена | `pip install vosk` |
| `Failed to load model` | Неверный путь к папке модели | Убедитесь, что папка называется `vosk-model` и находится рядом с `app.py` |
| Ассистент не реагирует | Не произнесено триггерное слово | Скажите «крендель» перед командой |
| Распознаёт, но выполняет не ту команду | Мало примеров в `data_set` | Добавьте 2–3 вариации фразы для этой команды |
| `PortAudioError` | Не найден микрофон | Проверьте подключение устройства, запустите `python -c "import sounddevice; print(sounddevice.query_devices())"` |
| Ошибка API погоды | Неверный или устаревший ключ | Обновите `appid` в `skills.py` |
