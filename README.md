# krendl

Голосовой ассистент на Python с распознаванием речи через Vosk и синтезом речи через pyttsx3. Команды классифицируются моделью логистической регрессии (scikit-learn) — ассистент сам понимает близкие по смыслу фразы.

---

## Установка

```bash
pip install scikit-learn sounddevice vosk pyttsx3 requests deep-translator
```

Скачать модель Vosk для русского языка: https://alphacephei.com/vosk/models
Распаковать в папку `vosk-model/` рядом с `app.py`.

---

## Запуск

```bash
python app.py
```

После запуска ассистент слушает микрофон. Для активации скажи одно из слов-триггеров:

- **крендель**
- **кренделек**

---

## Доступные команды

### Погода
| Пример фразы | Действие |
|---|---|
| крендель, какая погода | Озвучивает температуру и описание погоды во Владивостоке |
| кренделек, что там на улице | То же самое |

> API: OpenWeatherMap. Ключ прописан в `skills.py → weather()`.

---

### Браузер
| Пример фразы | Действие |
|---|---|
| крендель, открой браузер | Открывает YouTube в браузере по умолчанию |
| крендель, посмотреть фильм | То же самое |

---

### Игра / программа
| Пример фразы | Действие |
|---|---|
| крендель, запусти игру | Запускает exe-файл (путь настраивается в `skills.py → game()`) |

---

### Перевод текста
| Пример фразы | Действие |
|---|---|
| крендель, переведи как дела | Переводит «как дела» на английский и озвучивает |
| крендель, переведи текст добрый вечер | Переводит «добрый вечер» |
| крендель, нужен перевод привет мир | Переводит «привет мир» |

> Используется `deep-translator` (GoogleTranslator). Язык источника определяется автоматически, цель — английский.

---

### Курс валют
| Пример фразы | Действие |
|---|---|
| крендель, какой курс доллара | Озвучивает курс USD к рублю по данным ЦБ РФ |
| крендель, курс евро | Озвучивает курс EUR |
| крендель, курс USD | По коду валюты |

Поддерживаемые названия: `доллар`, `евро`, `юань`, `фунт`, `иена`, `франк`.
Поддерживаемые коды: `USD`, `EUR`, `CNY`, `GBP`, `JPY`, `CHF`.

> Источник: ЦБ РФ XML API (`cbr.ru/scripts/XML_daily.asp`).

---

### Управление
| Пример фразы | Действие |
|---|---|
| крендель, выключи компьютер | Выключает ПК (команда закомментирована — раскомментировать в `skills.py`) |
| крендель, отключись | Завершает работу ассистента |

---

### Разговор
| Пример фразы | Действие |
|---|---|
| крендель, привет | Приветствие в ответ |
| крендель, как у тебя дела | Ответ о состоянии |
| крендель, что ты умеешь | Перечисляет навыки |
| крендель, справка | То же самое |
| крендель, расскажи анекдот | Рассказывает анекдот |

## Структура проекта

```
krendl/
├── app.py          # Точка входа: захват аудио, распознавание, классификатор
├── skills.py       # Функции-навыки (weather, browser, translator, exchange, ...)
├── words.py        # Триггеры, датасет фраз, маппинг валют
├── voice.py        # Синтез речи через pyttsx3
└── vosk-model/     # Языковая модель Vosk (скачивается отдельно)
```

---

## Как добавить новую команду

1. Написать функцию в `skills.py`:
    ```python
    def my_skill():
        voice.speaker('Делаю что-то полезное')
    ```

2. Добавить фразы в `data_set` в `words.py`:
    ```python
    'сделай что-нибудь': 'my_skill сейчас сделаю',
    'выполни задачу': 'my_skill выполняю',
    ```
    Формат значения: `'имя_функции текст_ответа'`

3. Перезапустить `app.py` — модель обучается автоматически при старте.

### Команда с аргументом

Если функция принимает аргумент (как `translator` или `exchange`), добавь обработку в `recognize()` в `app.py` по аналогии с существующими блоками `if func_name == 'translator'`.

## Зависимости

| Библиотека | Назначение |
|---|---|
| `vosk` | Распознавание речи офлайн |
| `sounddevice` | Захват аудио с микрофона |
| `pyttsx3` | Синтез речи офлайн |
| `scikit-learn` | Классификация команд (LogisticRegression + CountVectorizer) |
| `requests` | HTTP-запросы (погода, курс валют) |
| `deep-translator` | Перевод текста через Google Translate |
